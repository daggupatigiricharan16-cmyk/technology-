# NovaTech — Technology Product Website

A responsive promotional landing page for a fictional smartphone concept, Nova X.

## Included
- Product hero section and product imagery
- Feature highlights: camera, display and battery
- Specifications section
- Colour selection interaction
- Product pricing and storage options
- Sample customer reviews
- Purchase call-to-action with demo confirmation
- Responsive navigation and mobile layout

## Run
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Internet access is needed for remote Unsplash images and Google Fonts.

## Customize
- Product copy, images, specs, price and reviews: `index.html`
- Design and responsive styling: `styles.css`
- Interactions: `script.js`

## Important
Nova X is a fictional product concept. Specifications, price, ratings, reviews and purchase benefits are illustrative placeholders, not verified product claims. The purchase button is a demo and does not process payments or create orders.
